# Clippi brand assets

- `clippi-mark.png`: single-sheet brand mark with real alpha transparency; no outer tile. Used in macOS and Windows headers.
- `clippi-app-icon.png`: matching app icon with a pale blue rounded tile. The packaged macOS PNG and Windows ICO are resized exports.

The mark keeps one white sheet and a cyan lower-right curl. Avoid additional stacked sheets, duplicate borders, or heavy glass effects. Interface colors use cool neutral surfaces and restrained blue accents, with separate light and dark palettes.
