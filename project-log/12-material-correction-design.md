# 素材校正工作区设计

> 状态：已实现，待 macOS 26 arm64 CI 与真实素材验收
> 日期：2026-09-05

## 目标

为拍摄素材提供单条和批量统一的画面校正工作流。用户可以导入文件或文件夹，预览每条视频，逐条或批量设置 90°/180° 旋转、左右镜像和上下镜像，然后统一输出后再进入任意剪辑软件。

ffmpeg 与 ffprobe 始终随 Clippi 安装包提供，用户不安装、不配置外部媒体环境。

## 已确认范围

- 支持单文件、多文件和文件夹导入；文件夹只读取当前层。
- 支持逐条调整、对已勾选素材应用、对全部素材应用。
- 支持左转 90°、右转 90°、旋转 180°、左右镜像、上下镜像和重置，且可以组合。
- 选中素材可播放预览，预览即时体现校正结果。
- 不使用 AI 判断画面方向。
- 串行处理，单项失败后继续队列，默认不覆盖原始素材。
- Windows x64 与 macOS 26 Apple Silicon arm64 为发布验证目标。

## 页面结构

1. 顶部工具栏：工具切换、添加文件、添加文件夹、清空。
2. 左侧素材列表：勾选范围、媒体信息、校正摘要和处理状态。
3. 右侧预览与校正：视频播放器、方向操作、重置和批量应用范围。
4. 底部输出栏：输出位置、待处理数量、覆盖策略和主操作按钮。

蓝色高亮行表示当前预览素材；勾选框表示批量应用与处理范围。两种状态不得混用。

## 方向语义

- 系统播放器先按源视频 display matrix / rotate 元数据展示素材。
- 用户操作始终相对于当前可见画面。
- ffmpeg 转码时应用源方向元数据，再应用用户指定的旋转与镜像。
- 输出清除旋转元数据，避免剪辑工具二次旋转。
- 最终目标是“输出画面与 Clippi 预览一致”。

## 输出规则

- 默认在每个源文件所在目录创建 `Clippi-output`。
- 统一输出剪辑兼容的 MP4；保留源文件名主体，同名输出自动添加序号。
- 保持原分辨率和帧率；SDR 使用高质量 H.264，检测到 HDR/10-bit 时使用 10-bit HEVC；音频转为 192 kbps AAC 并保留全部音轨。
- 未设置用户校正且无源旋转元数据的素材默认跳过。

## 核心模型

- `FileInfo.rotation_degrees`：标准化后的源方向元数据。
- `Operation::Transform`：用户旋转、水平镜像和垂直镜像。
- 每条素材保存自己的变换、勾选状态、任务 ID、进度与终态；输出路径在任务规划时统一生成并避让冲突。
- 队列串行执行；回调通过 task ID 精确更新对应素材。
- 原生播放器不能解码时，由内置 ffmpeg 生成临时首帧预览图，方向操作仍可预览。

## 验收矩阵

- 无方向元数据、90°/180°/270° 元数据分别输出为物理正向且无残留方向标签。
- 左右镜像、上下镜像、旋转与镜像组合的预览和输出一致。
- 准备中或处理中点击停止，当前及剩余任务均不再启动。
- 单项失败继续后续任务；完成项不重复入队，失败/取消项允许重试。
- 文件夹只读取当前层；重复导入不产生重复项；同名输出自动避让。
- MP4/MOV/M4V/MKV/WebM/AVI/MTS/M2TS/TS/MPG/MPEG/WMV/FLV/3GP 可导入处理；原生播放器失败时显示首帧兜底预览。
- SDR、10-bit/HDR、多音轨素材验证输出编码、色彩标记、音轨数量与剪辑软件兼容性。
- Windows 和 macOS 发布包在无外部 ffmpeg 环境的干净机器运行。

## 非目标

- AI 或内容识别方向。
- 递归文件夹扫描。
- 覆盖或删除源文件。
- 多个 ffmpeg 任务并行运行。
- 要求用户自行安装 ffmpeg。
