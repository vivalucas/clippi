# 使用与管理指南

> 适用状态：启用。面向用户的完整安装与功能介绍以根 [README](../README.md) 为准；本文补充维护者容易混淆的操作边界。

## 用户操作摘要

1. 导入素材；等待元信息读取完成。
2. 选择裁剪、转换、缩放、旋转与镜像或音频处理。
3. 设置参数和输出位置；开始后参数会锁定。
4. 观察进度、速度和状态；需要时取消。完成后从实际输出路径定位文件。
5. 失败时先按短提示恢复，需要排查再复制技术详情。应用不会覆盖或删除源文件。

素材校正可导入多个文件或文件夹当前层。当前预览行与批量复选框含义不同；设置方向后选择应用范围，再串行处理。没有校正且没有源方向的项目会跳过。

## 安装提示

- macOS 包未签名/公证，按系统允许方式打开；若 README 提供 `xattr -cr`，只对明确下载并信任的 `Clippi.app` 使用。
- Windows 包未代码签名，SmartScreen 可能提示；安装版、便携自解压版和 zip 版内容来源相同但使用方式不同。
- 发布包已经内置 ffmpeg/ffprobe，不要求用户安装；开发者环境见 [07](07-environment.md)。

## 完成检查与恢复

- 输出存在且可播放、方向与预览一致、源文件未改变，才算用户路径完成。
- 同名输出会自动避让；核心拒绝覆盖。失败/取消项可以调整路径或参数后重试。
- 应用没有任务历史数据库；退出前需要自行确认输出。偏好异常时可在设置恢复外观/默认目录，必要时再清理 [05](05-data-design.md) 所列的本地偏好文件。
