# 功能与业务约定

> 适用状态：启用。记录当前用户可用能力和真正影响实现的边界。

## 当前功能地图

| 功能 / 入口 | 用户任务 | 当前实现 / 代码依据 | 验收要点 |
| --- | --- | --- | --- |
| 导入与探测 | 拖拽或选择媒体，读取元信息 | `core/src/probe.rs`、两端 ViewModel | 只应用最新一次异步探测；失败不覆盖当前有效素材 |
| 裁剪 | 时间范围快速复制流或精确重编码 | `Operation::Trim` | 起止有限且顺序正确；结束超界夹到源时长；快速模式说明关键帧限制 |
| 格式转换 | 输出 MP4 / MKV / MOV / WebM | `Operation::Convert` | 容器与编码兼容；WebM 使用 VP9 / Opus；已有输出拒绝覆盖 |
| 缩放 | 4K / 1080p / 720p / 480p | `Operation::Scale` | 保持比例、适配目标范围、结果为正偶数尺寸，不强制拉伸 |
| 音频处理 | 提取 MP3/AAC/WAV 或移除音轨 | `ExtractAudio` / `RemoveAudio` | 无音轨时提前阻止提取；移除音频复制视频流，不无谓重编码 |
| 素材校正 | 单条/多条旋转与镜像 | `Operation::Transform`、两端 correction workspace | 预览与输出方向一致；源方向先应用；队列串行、可停止、失败继续 |
| GPU 探测 | 自动选择硬件编码能力 | `core/src/gpu.rs` | VideoToolbox / NVENC / QSV 探测超时后安全回退 CPU |
| 进度与错误 | 展示百分比、速度、ETA、终态 | `-progress pipe:1`、FFI callback | 只以 `state` 判定终态；用户提示与可复制技术详情分层 |
| 输出控制 | 设置目录、命名、取消 | 两端 ViewModel + Rust `-n` | 自动避让同名；路径可写；不覆盖源文件；处理时锁定参数 |

## 媒体与导入规则

- 普通工具接受常见视频及纯音频文件；具体扩展名白名单由两端 ViewModel 维护，底层仍以 ffprobe 实际结果为准。
- 纯音频不能执行缩放、旋转/镜像或移除音频；UI 应在启动任务前给出可恢复提示。
- 素材校正接受单文件、多文件和文件夹当前层，不递归扫描；重复路径不产生重复项。
- 蓝色/选中行表示当前预览素材，复选框表示批量应用和处理范围，两种状态不可混为一谈。

## 素材校正语义

1. 系统播放器先按源文件 display matrix / rotate 元数据展示素材。
2. 用户的旋转与镜像相对于当前可见画面，可组合并即时预览；播放控制条不参与画面变换。
3. ffmpeg 解码阶段应用源方向，再应用用户校正并烘焙像素；输出清除旋转标签。
4. 校正输出统一为 MP4：SDR 使用 H.264，HDR/10-bit 使用 HEVC，保留元数据，全部音轨转 AAC 192 kbps。
5. 默认输出到各源目录的 `Clippi-output`；设置了默认目录或当前批量目录时优先使用。批量规划阶段必须同时避让磁盘现有文件和本批次预留文件名。
6. 未设置用户校正且没有源方向元数据的条目默认跳过；完成项不重复入队，失败/取消项可重试。

## 队列与取消

- 同一时间只运行一个 ffmpeg 任务，避免 GPU/CPU 与磁盘争用。
- 队列先统一校验并注册全部 task ID，再由后台线程逐项准备和执行；前端先登记全部 ID，才能安全接收早到回调。
- 停止全部需要覆盖准备中、排队中和处理中任务；单项失败不阻断后续项目。
- 队列返回 ID 数量与请求不符时，前端取消已返回 ID、使旧回调失效并恢复为可重试状态。

## 当前限制与非目标

- 除素材校正外，裁剪、转换、缩放和音频工具仍是单文件流程。
- 没有输出大小预估、磁盘空间预警、可编辑 ffmpeg 命令、完整日志浏览器或持久任务历史。
- 不做 AI 方向识别、递归目录、源文件覆盖/删除、并行处理、云端处理或多轨视频编辑。
