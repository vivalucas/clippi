# UI 与交互约定

> 适用状态：启用。当前代表页面是常驻工具侧栏 + 单任务工作区，以及素材校正工作区。

## 设计方向

Clippi 是简洁、工具感明确的原生生产力应用。两端共享页面层级、状态语义、蓝色强调色、品牌标记和文案含义；SwiftUI 与 WinUI 3 保留各自字体、标题栏、控件和平台交互，不追求逐像素相同。

## 项目实现入口

| 内容 | 唯一维护位置 / 参考 |
| --- | --- |
| macOS 主题与页面 | `macos/Clippi/Views/MainView.swift` |
| macOS 状态与业务交互 | `macos/Clippi/ViewModels/MainViewModel.swift` |
| Windows 主题资源 | `windows/Clippi/App.xaml` |
| Windows 页面 | `windows/Clippi/MainWindow.xaml` / `.xaml.cs` |
| Windows 状态与业务交互 | `windows/Clippi/ViewModels/MainViewModel.cs` |
| 品牌源资源 | `assets/brand/`；界面用透明 mark，应用图标用带底板版本 |
| 本地化 | macOS `.lproj`、Windows `.resw`，简中/英文/日文键义保持一致 |

## 信息架构

- 左侧五个平级工具：裁剪、格式转换、缩放、旋转与镜像、音频处理；音频页内切换提取/移除。
- 设置固定在侧栏底部，包含跟随系统/浅色/深色和默认导出位置。当前任务参数与单次输出路径不得移入全局设置。
- 切换普通工具保留当前素材；从普通工具进入素材校正可同步当前素材，但从设置返回或重复点击入口不能重选旧素材或重置校正状态。
- 切换输出格式保留用户自定义目录和文件名主体，只调整扩展名；修改默认导出目录只影响之后的新导入和未单独指定目录的批量任务。

## 页面与反馈规则

- 每页只有一个明确主任务；可用参数随当前素材和操作显示，空状态不展示无法操作的表单。
- 处理期间锁定会影响已启动配置的入口、参数和路径，防止界面状态与运行任务产生错觉。
- 导入、准备、排队、处理、完成、失败、取消都必须有可见状态；完成后的定位动作使用实际输出路径。
- 失败先展示简短可恢复提示，再提供复制原始详情；不要直接把含本机路径的整段 ffmpeg stderr 当普通提示。
- 视频预览只变换画面，不变换播放/进度控件；原生播放器不支持时显示内置 ffmpeg 生成的等比首帧 JPEG。
- 素材校正中当前预览和批量勾选是独立概念；完成、失败和取消项必须可辨认。
- 支持键盘可达的文件选择与设置入口；macOS `Command+,` 打开设置。新增控件同时检查明暗主题、焦点、禁用态、窄窗口与滚动。

## 验收

UI 改动至少检查：五个入口和设置往返、素材保留、空/加载/失败/禁用状态、文件选择与拖拽、输出路径、取消后重试、预览与最终方向、明暗模式和本地化。可运行时查看真实窗口；XAML/XML 解析或编译通过不能代替 Windows 视觉与交互验收。
