# 决策与经验

仅保留仍约束当前项目的取舍和能阻止重复犯错的经验。记录按新到旧排列。

## D-007：五工具导航、独立设置与双端品牌语义

- **状态与日期**：当前有效，2026-09-12。
- **选择**：裁剪、转换、缩放、旋转与镜像、音频处理同级；设置固定侧栏底部。共享品牌、信息层级、状态语义和本地化含义，原生控件保留平台差异。
- **依据**：避免把旋转误作产品主功能，也避免把单次任务参数塞进全局设置。
- **执行**：改 UI 先读 [03](03-ui-design.md)，检查设置往返、素材保留和双端语义，不以 Web UI 统一两端。
- **重评**：产品入口数量或主流程发生实质变化时。

## D-006：素材校正使用统一工作区和组合变换

- **状态与日期**：当前有效，2026-09-05；2026-09-12 更新入口和默认目录优先级。
- **选择**：单文件视为单项队列；逐条预览，可对勾选或全部素材应用 90°/180° 旋转及双向镜像。源方向先应用，用户校正烘焙到像素并清除方向标签；统一输出 MP4，串行队列。
- **依据**：仅改元数据在不同剪辑软件中不一致；旧单文件表单无法表达批量状态；AI 判断方向不在需求内。
- **代价**：需要重编码，HDR/多音轨兼容矩阵扩大；播放器失败需首帧兜底。
- **执行**：预览与输出必须所见即所得；回归覆盖方向组合、队列取消、失败继续、输出避让。
- **重评**：需要无损元数据模式、递归媒体库或并行调度时。

## D-005：裁剪同时提供快速与精确模式

- **状态与日期**：当前有效，2025-05-14。
- **选择**：快速模式复制流，速度快但受关键帧影响；精确模式重编码以获得帧级起点。
- **执行**：UI 明示取舍；起止必须有限、有效并夹到源时长，进度使用实际区间。

## D-004：ffmpeg 任务串行执行

- **状态与日期**：当前有效，2025-05-14；2026-09-05 完善可取消队列。
- **选择**：同一进程一次只运行一个 ffmpeg 任务，队列预先注册全部 ID 后逐项准备。
- **依据**：并行会争抢 GPU/CPU/磁盘且部分硬件编码器多实例行为不可控。
- **执行**：不得在 `queue_tasks` 中循环调用会各自 spawn 的异步单任务形成伪串行；取消通道必须进入统一注册表。
- **重评**：有明确吞吐基准和资源调度策略时。

## D-003：采用 monorepo

- **状态与日期**：当前有效，2025-05-14。
- **选择**：`core`、`macos`、`windows`、构建脚本和发行配置在同一仓库。
- **依据**：C ABI 和双端行为需要同一提交同步演进，便于跨端审查和发布。

## D-002：ffmpeg / ffprobe 随应用打包

- **状态与日期**：当前有效，2025-05-14。
- **选择**：二进制不入 Git，开发和 CI 通过脚本下载并校验，发布产物内置；运行时仍允许环境变量和 PATH 作为开发回退。
- **依据**：普通用户无需安装，减少环境差异。
- **代价**：包体较大，下载源和许可证需要持续维护；Windows 当前 rolling 构建会漂移。
- **执行**：每次发布核对包内布局和 SHA256 校验，媒体版本变化后重跑真实 FFI 测试。

## D-001：双原生 UI + Rust 核心

- **状态与日期**：当前有效，2025-05-14。
- **选择**：macOS SwiftUI、Windows WinUI 3，共享 Rust 核心；不采用 Electron、Tauri 或纯 Rust GUI。
- **依据**：保持原生体验和较低运行开销，同时复用媒体逻辑。
- **代价**：两套 UI 和 FFI 增加维护/验证成本。
- **执行**：业务规则优先集中在 core；接口变更同时检查 Rust/Swift/C#；平台 UI 不复制任务引擎。
- **重评**：双端维护成本无法接受或产品转为 Web/云端时。

## 防复发经验

- ffmpeg 结构化进度必须显式使用 `-progress pipe:1` 并读取 stdout；stderr 只作错误详情。
- Swift C callback 不能捕获上下文；C# delegate 必须保留强引用；两端都以 task ID 字典隔离并发回调。
- 前端不能把 100% 当终态，只处理 `completed` / `failed` / `cancelled`。
- 新 Swift 文件要确认进入 PBXSourcesBuildPhase；WinUI 3 不照搬 WPF/UWP 属性和绑定语法。
- CI artifact 不是 GitHub Release 资产；宣称发布完成前同时核对 workflow 结论和 Release 资产。
- 输出保护双层实现：UI 规划时避让，Rust/ffmpeg 使用 `-n` 拒绝覆盖。
